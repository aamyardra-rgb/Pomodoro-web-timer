🍅 Pomodoro Timer Web App

A modern and responsive Pomodoro Timer built using HTML, CSS, and JavaScript.
This productivity app helps users manage work sessions and breaks efficiently using the Pomodoro Technique.

🚀 Features

 25-minute Pomodoro session
 5-minute Short Break
 15-minute Long Break
 Animated circular progress indicator
 Alarm sound when timer ends
 Dark mode toggle
 Clean and modern UI

🛠️ Technologies Used

HTML5
CSS3 (Flexbox, Gradients, Animations)
JavaScript (DOM Manipulation, setInterval)
